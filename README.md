# Amazon Homepage Clone

A responsive Amazon homepage clone built using HTML5 and CSS3 to strengthen front-end fundamentals and recreate a production-inspired user interface.

## 🚀 Features

- Responsive Layout
- Navigation Bar
- Hero Banner
- Product Cards
- Footer
- Clean HTML Structure
- CSS Flexbox

## 🛠 Tech Stack

- HTML5
- CSS3
